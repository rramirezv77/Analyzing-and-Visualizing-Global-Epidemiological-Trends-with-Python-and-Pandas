# Analyzing-and-Visualizing-Global-Epidemiological-Trends-with-Python-and-Pandas

# 1 Comprobar Python y pip (asegúrate de usar el intérprete correcto)

```py
python --version
python -m pip --version
```

# 2 Actualizar pip e instalar Streamlit en el entorno actual

```py
python -m pip install --upgrade pip
python -m pip install streamlit
```

# 3 Ejecutar la app usando el módulo (evita depender del PATH)

```py
python -m streamlit run filename.py
```

# 4 Instalar modulo plotly (para ver los graficos)

```py
python -m pip install plotly
```

# 4 Instalar módulos para perfilado de datos

```py
python -m pip install ydata-profiling -q
python -m pip install ipywidgets
```
